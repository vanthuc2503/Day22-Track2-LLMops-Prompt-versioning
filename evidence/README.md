## How to Save Evidence

### Save console output to file (Linux/Mac)
```bash
python 02_prompt_hub_ab_routing.py 2>&1 | tee evidence/02_ab_routing_log.txt
python 04_guardrails_validator.py  2>&1 | tee evidence/04_pii_demo_log.txt
```

### Copy RAGAS report
```bash
cp data/ragas_report.json evidence/03_ragas_report.json
```
